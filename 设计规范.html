01 · 设计理念与用户习惯

界面不是给"用户"用的，是给"老师"用的。方案的每一条规则都锚定一个真实工作习惯：

教师工作习惯界面对策
一切工作以学期、教学周为节律周次胶囊常驻顶栏最左侧（赭金），全站任何页面都能一眼看到"现在是第几周"；日期型信息一律用赭金系强调
一天要扫读几千行表格（成绩/考勤/台账）表格工程四件套：等宽数字对齐、行高 40px、总评列浅靛底色、预警行红左条 + 浅红底
录入越快越好（30 秒原则）顶栏常驻「＋ 快速录入」主按钮，聚合六类高频录入入口；表单默认值、下拉选择、粘贴导入保持不变
打开首页先问"今天该干嘛、谁要盯"仪表盘 F 型动线：问候语 → 四张统计卡 → 未来 14 天时间轴（左 2/3）→ 今日课表 + 预警栏（右 1/3）
期末材料要打印上交打印样式继承：去侧栏去按钮、白底卡片、表格不跨页断裂
颜色的稀缺性原则：全站仅三种颜色有"报警权"——绿（正常完成）、橙（待跟进预警）、红（旷课/不及格/逾期）。上一版导航 6 模块 6 色小方块的做法取消：颜色当模块身份证用，会稀释状态色的报警能力。

03 · 字体排印

层级规格字体用途
页面标题21px / 500衬线（思源宋体栈）"数据结构 · 成绩册"——每页仅一处，学院气质的锚点
卡片标题15–16px / 500无衬线「未来 14 天」「今日课表」
正文 / 表格13–14px / 400无衬线行高 1.6；表格行高 40px
次级 / 弱12px / 400无衬线说明、占位、统计卡标签
数字tabular-numsConsolas 栈学号、成绩、金额——等宽对齐，录入不抖动

衬线只用两处：品牌名与页面标题。整站衬线会造成阅读疲劳，一处点睛即可确立气质。

05 · 组件规范

5.1 周次胶囊（新增 · 全站时间坐标）

第 3 教学周 · 秋季学期 未设置学期

位置：顶栏最左侧。无学期时同样式但内容提示"未设置学期"。它是全站唯一默认可见的赭金元素——节拍器永远点着灯。

5.2 按钮

规则说明
一屏一个主按钮主按钮是当前视窗内最想要的那个动作（保存 / 导出 / 快速录入），其余一律降级
危险操作双确认删除走模态确认，按钮红色仅出现于确认框与最终操作
焦点可见:focus-visible 时 2px 靛蓝外框 + 2px 偏移，键盘用户不迷路

5.3 状态徽章 · 业务语义映射（全站唯一真源）

出 · 出勤迟 · 迟到旷 · 旷课假 · 请假
国家级省级校级
在研结题待跟进
优秀正常预警缺考

竞赛级别只用靛蓝/灰区分，不用金色——金色是时间色，不给状态用。级别含金量靠排序体现，不靠颜色。

5.6 空状态

空状态必须回答两件事：这里放的是什么数据 + 现在就能做什么。图标用几何圆环不用插图，避免跨端违和。

06 · 页面级规范

区域规格要点
侧栏宽 224px · 白底 · 右侧 1px 描边分组（总览/业务/归档/系统）+ 激活项靛蓝胶囊白字；导航图标统一中性空心圆点

成绩册面包屑 → 衬线页题 → 信息胶囊 → 标签页 → 表格 → 分布与预警双卡表格列序固定：标识列 → 过程列 → 结论列（总评）→ 状态列

07 · 可访问性（WCAG 2.1 AA）

组合对比度判定
墨 #1F2733 / 纸底 #F7F5F1≈ 13.9 : 1AAA，正文主组合
靛蓝 #2F5D8F / 白卡面≈ 6.9 : 1AA，链接与主按钮文字
白字 / 靛蓝底（主按钮）≈ 6.9 : 1AA
赭金深 #97590C / 赭金底 #FBF0E4≈ 5.0 : 1AA，胶囊文字必须用 700 号深金
朱红 #C2402A / 白≈ 5.2 : 1AA，预警文字
松绿 #2E7D5B / 白≈ 5.0 : 1AA
禁用组合：赭金 500（#C77D2E）直接作小号文字色（对白仅 3.3:1）——它只允许做图形底色与大号数字；弱文本 #8B94A1 仅用于 ≥12px 的辅助信息，不作正文。

交互附加项：全部按钮/导航/输入可 Tab 触达且焦点可见；预警行三重编码（色之外有位置与文字）服务色弱用户；触控目标 ≥ 40px（表格行高即保证）；动画仅 150–300ms 过渡，不做视差与弹跳。
