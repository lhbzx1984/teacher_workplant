# 高校教师工作台

面向高校教师（授课 + 班主任 + 竞赛指导 + 科研）的本地工作台：**无需安装、无需服务器、无需注册，双击即用**。所有数据只存在你自己的浏览器里，不经过任何网络传输。

## 功能总览

| 模块 | 覆盖内容 |
| --- | --- |
| 仪表盘 | 教学日历（月视图：课程时段 + 监考/答辩/特殊日程 + 跟踪事项 + 工作台账，已上/进行中/未上状态随时间实时刷新）、明日提醒、当前教学周、待办提醒、各业务快照 |
| 课程教学 | 课程档案（含授课时段排课与考核方式，理论/实验/实践/上机分列）、名单（Excel/粘贴批量导入）、加权成绩册、考勤、作业实验、教学进度 |
| 班主任学生管理 | 全局学生档案池、**工作台账**（谈话/走访/班会/活动 + 评奖评优/就业/贫困生申报等类型，按类型着色同步日历）、**跟踪事项**（准备/完成两态，可从台账一键转事项或关联台账，同步日历与明日提醒）、评奖评优、**统计分析**（独立模块：台账分类/月度趋势/事项完成率/就业资助动态/学生活跃度） |
| 学科竞赛 | 竞赛库、指导团队、获奖成果、**报名截止/决赛时间可选跟踪**（红色同步日历 + 明日提醒） |
| 科研项目 | 项目台账、进度节点（**可逐节点跟踪**，同步日历）、经费记录、成果库 |
| 考核汇总 | 按学年自动汇总各项工作量，支持打印 |
| 学期与设置 | 学期管理、特殊日程（监考/毕业答辩/课程答辩/特殊事件）、教师信息（学校/学院/教师专业，保存后显示在侧边栏）、数据备份与恢复 |

顶栏的「＋ 快速录入」聚合了六类高频录入入口；顶栏常驻显示当前学期与教学周。

侧边栏还提供**使用说明向导**：位于「学期与设置」下方，点击后弹出分步悬浮向导，8 步可视化动态演示工作台的完整使用流程（建立学期 → 课程教学 → 学生台账 → 跟踪事项 → 科研竞赛跟踪 → 教学日历 → 数据安全），支持上一步/下一步、进度点跳转、自动播放与键盘 ← → 翻页。

## 快速开始

1. 点击本页面上方绿色 **Code** 按钮 → **Download ZIP**，解压到任意文件夹（或 `git clone` 本仓库）
2. 双击 `index.html`，在浏览器（推荐 Chrome / Edge）中打开
3. 首次打开会自动载入一份演示数据，熟悉界面后到「学期与设置 → 数据管理 → 清空全部数据」从零开始
4. 建议的第一步操作：「学期与设置 → 新增学期」——开始日期填**开学第一周的周一**，系统据此自动计算当前教学周

## 数据存在哪里（重要）

- 所有数据保存在**当前使用的浏览器**的本地存储（localStorage）中
- 意味着：**换浏览器、换电脑、或清理浏览器数据，都看不到原来的数据**——数据仍留在原来那个浏览器里，并没有丢失
- 多人各自使用本工具时，数据相互独立、互不干扰（每人存在各自的浏览器中）

因此请养成备份习惯，见下节。

## 备份与恢复

| 操作 | 路径 | 说明 |
| --- | --- | --- |
| 备份 | 学期与设置 → 数据管理 → **导出备份（JSON）** | 得到一个 `.json` 文件，建议每学期初、期末各导出一次，存到网盘或 U 盘 |
| 恢复 | 学期与设置 → 数据管理 → **从备份文件恢复** | 选择之前导出的 `.json` 文件即可还原全部数据 |
| 换电脑 | 备份 + 恢复 | 旧电脑导出 `.json`，拷到新电脑，双击 `index.html` 后恢复 |

## 学生名单批量导入

1. **下载模板**：学期与设置 → 数据管理 → 「下载学生导入模板」（学生管理页的导入弹窗里也有同名入口）。模板含「学生名单」与「填写说明」两个工作表
2. **两种导入方式**：
   - 选择 `.xlsx` 文件上传
   - 或直接在 Excel 中复制表格区域，粘贴进导入弹窗（完全离线可用）
3. **导入即更新（不会重复建档）**：系统按学号识别同一学生（其次按姓名 + 班级）。已存在的学生会更新其信息，新学生才建档——所以学生信息有变时，把新名单再导一次即可自动刷新

> 说明：`.xlsx` 文件解析需要联网加载解析库（SheetJS CDN）；完全离线时使用「粘贴」通道即可。

## 教学日历

1. **排课**：在「课程教学 → 新增/编辑课程」中填写**授课时段**（类型分理论/实验/实践/上机，周几 + 起止时间，一门课可多个时段），每个时段可设置**上课地点**（教室/实验室/机房，同步显示在日历条目上）与**上课周数**（第 X–Y 周，支持每周 / 单周 / 双周——实验课双周排一次很常见），并可指定**考核方式**（闭卷考试/开卷考试/考查/论文报告/机试/其他）
2. **特殊日程**：在「学期与设置 → 特殊日程」登记监考、毕业答辩、课程答辩、特殊事件（可关联课程、填地点与备注）
3. **跟踪事项**：在「班主任学生管理 → 跟踪事项」登记班级事务（班会、收缴、材料提交等），状态分**准备 / 完成**；完成后日历条目变**绿色**、未完成显示**琥珀色**、过期未完成显示**红色**
4. **工作台账**：在「班主任学生管理 → 工作台账」登记班级工作，类型覆盖**谈话 / 走访宿舍 / 班会 / 活动 / 评奖评优 / 就业 / 贫困生申报 / 其他**，条目按类型着色显示在日历；带跟进安排的台账可**一键「转跟踪事项」**，新增跟踪事项时也可从台账下拉选择关联——关联后日历与事项列表会显示台账类型标签
5. **科研节点跟踪**：在「科研项目 → 项目详情 → 节点管理」中，添加节点时可勾选**同步到日历**，已有节点可随时点**跟踪 / 取消跟踪**；跟踪中的节点以**红色**显示在日历（已完成的显示**绿色**），点击直达项目详情
6. **竞赛时间跟踪**：在「学科竞赛 → 新增/编辑竞赛」中可分别勾选跟踪**报名截止**与**决赛时间**，详情页也可一键切换；跟踪的时间点以**红色**显示在日历，竞赛列表与详情页带「跟踪中」徽章
7. **明日提醒**：仪表盘顶部横幅自动列出**明天到期**的跟踪类条目——跟踪事项、跟踪中的科研节点、跟踪的竞赛报名截止/决赛（提前一天提醒），点击条目直达处理
8. **日历展示**：仪表盘教学日历按**月**呈现以上全部日程（周一为每周起点，周一格标注教学周次），支持月导航（‹ 本月 ›）；课程严格按各时段的周数范围与单双周落位；课程理论（靛）/实验（紫）/实践（青碧）/上机（琥珀）、日程类型、台账类型以不同底色区分；课程时段填写的**教室/实验室/机房**与特殊日程的地点以灰色小标签直接显示在日历条目上（悬停可见完整信息）
9. **实时状态**：已上/已结束（灰化）、进行中（金色高亮 + 闪烁指示）、未上/未开始（正常色），页面每 30 秒自动刷新状态，无需手动操作

## 教师信息

在「学期与设置 → 教师信息」中填写**学校 / 学院 / 教师专业**（连同姓名、工号）后，左侧边栏「学期与设置」下方会以三行展示：第一行学校（加粗）、第二行学院、第三行教师专业；三项均为空时不占位。这些信息同时用于**考核汇总**页的署名行。

## 技术说明（开发者向）

- 纯 vanilla JavaScript 单页应用：无框架、无构建步骤、无依赖安装（SheetJS 按需从 CDN 加载）
- 结构：`js/data.js`（数据层）+ `js/ui.js`（组件层）+ 各业务模块 + `js/main.js`（hash 路由）
- 核心模型约定：**学期为全局时间轴**（自动计算教学周）；**学生为全局实体**（课程名单、班主任台账、竞赛团队均引用同一档案池，一处建档多处复用）
- UI 设计语言「纸·墨·金」，详见仓库内 `设计规范.html`（活样式指南，含色彩令牌、组件规范与 WCAG AA 对比度表）
